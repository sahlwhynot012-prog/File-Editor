Connect Google Sign-In

To sign in with Google, this site needs a free OAuth client ID. It takes about three minutes, once.

  1. Open console.cloud.google.com → create a project → APIs & Services → Library → enable Google Drive API (and Google Picker API if you want to browse all of Drive).
  2. OAuth consent screen → External → add the scope .../auth/drive.file.
  3. Credentials → Create credentials → OAuth client ID → Web application. Under Authorized JavaScript origins add this address:
  4. Paste the client ID into config.js (CLIENT_ID), redeploy, and reload.
